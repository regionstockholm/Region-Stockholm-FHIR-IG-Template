# Om - Region Stockholm FHIR Implementation Guide Template v2.3.0

## Om

### Styrning och förvaltning

FHIR-profiler förvaltas av Region Stockholm: Lägg till källkod###

En beskrivning av krav på följsamhet samt vägledning vid implementering av Region Stockholm FHIR-IG:ar finns på - Lägg til länk###

Sidan ger en översikt av krav på system som vill ansluta sig till Region Stockholms tjänster via FHIR.

Ssidan erbjuder även stöd för utvecklare som vill förstå hur de arbetar med Region Stockholms FHIR-standarder, inklusive en guide för att läsa en Implementation Guide och instruktioner för hur man använder FHIR-verktyg som valideringsuppsättning.
